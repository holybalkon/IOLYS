Parallel tasks share the limits of the provider accounts they use. Separate workspaces keep edits apart; they do not increase subscription quotas.

FAQ

Clear answers before you choose a route.

Is there a Visual Studio extension supporting multiple LLM providers?

Yes. iolys connects several AI providers and coding agents through one interface inside Visual Studio 2026, so you can switch between them without leaving your solution.

What is Bring Your Own Subscription (BYOS)?

BYOS means you connect an AI plan you already pay for, such as a ChatGPT account with Codex access. iolys acts as the harness; the provider bills you directly under their own terms.

How is BYOS different from Bring Your Own Model (BYOM)?

BYOS reuses a hosted subscription and its agent. BYOM points iolys at a specific model endpoint you provide, giving you more control over which model runs your tasks.

How do I use my ChatGPT subscription for coding in Visual Studio?

Install iolys, open View → Iolys Chat, choose Codex, and sign in through its CLI with a ChatGPT account whose plan includes Codex access. Then give it a focused .NET task.

Can I use Claude Code in Visual Studio?

Claude is a featured provider. Connect it through iolys following its own connection steps and eligibility rules, then use it as your coding agent inside your solution.

Can I run a local LLM in Visual Studio 2026?

Yes. Providers like Ollama let you run models locally. Point iolys at your local endpoint and work offline against your own hardware.

Does iolys support C# and .NET projects?

iolys is built for C# and .NET. It opens your existing solution, lets the agent build and test, and shows you the diff to review before you accept changes.

Which Visual Studio versions and operating systems does iolys support?

iolys targets Visual Studio 2026. Supported operating systems follow the Visual Studio 2026 requirements; check the Marketplace listing for the current details.

Is iolys free?

All currently available iolys features are free for personal and commercial use. Your AI provider's costs, quotas, and terms still apply separately.

Is iolys an AI provider?

No. iolys is an agent harness that connects you to third-party AI providers. It does not host its own model; it routes your work to the provider you choose.

Can I use my existing AI subscriptions?

Yes. iolys reuses eligible account access through supported provider CLIs, an OpenCode Go subscription through its API key, and your organization’s existing Databricks workspace. Provider eligibility and usage limits still apply.

Does it support local models?

Yes. iolys supports Ollama and is designed to work with local and self-hosted model routes alongside cloud providers.

Do I need to leave Visual Studio 2026?

No. The extension is built specifically for Visual Studio 2026 so conversations, workspace context, and agent activity stay close to your code.

Is iolys a VSIX extension, and how do I install it?

Yes. iolys is distributed as a VSIX extension for Visual Studio 2026 on 64-bit Windows. Install the VSIX from the Visual Studio Marketplace, or from Extensions > Manage Extensions inside Visual Studio, restart the IDE, then connect a provider from the Manage Providers panel.

What happens when I change providers?

The provider and model change; the core iolys interface, navigation, permission flow, and workspace context remain consistent.
